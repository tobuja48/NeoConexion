Dos páginas, una API real

  1. Abre la app original de vacantes en otra pestaña.
  2. En Integración NeoConexión, selecciona API NeoConexión por HTTP y usa el mismo servidor que este visor: .
  3. Guarda un perfil, publica una vacante o consulta compatibilidad. Esta página muestra la entrada y respuesta observadas por el servidor.

El archivo de vacantes se conserva exactamente como fue entregado. En modo embebido no llama a la API y no genera actividad en este visor. El visor muestra las solicitudes al servidor, incluso las realizadas desde Swagger. No cambia ni controla la página de vacantes.

El historial es temporal, compartido por los usuarios autorizados de esta API de prueba y se pierde al reiniciarla. El endpoint del visor utiliza la misma protección X-API-Key. No almacena cabeceras ni claves. Las respuestas demasiado grandes se señalan y no se muestran como JSON completos. La salida confirma una respuesta del servidor; no prueba que otro navegador ya la haya mostrado.
