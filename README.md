# NeoConexión

Reconstrucción incremental de la API de compatibilidad laboral. Python 3.12/3.13, FastAPI y Neo4j.

Los PRs se revisan en orden: cada rama depende de la anterior. La aplicación completa se ensambla en la entrega 28; Docker y documentación se incorporan al final. No hay fusiones automáticas.

Esta reconstrucción parte del repositorio vacío y reutiliza módulos del prototipo local ya comprobados, separando las reglas del motor y añadiendo historias del repositorio.

Instalación inicial: `python -m pip install -r requirements.txt`.
